## 人工验收步骤

1. 从托盘完全退出旧程序，运行 V1.1。确认旧任务/笔记仍存在。升级到模式 v2 后使用新版，旧 V1.0 不支持打开 v2。
2. 在月历点击某日期，新建普通任务，不设置截止；确认出现在所选日期。编辑计划日期，应移动到新日期。
3. 新建 Deadline，设置标题、描述和截止日期时间；确认粉色“◆”色块出现。修改截止日期，应从旧日移到新日；勾选完成后可在当天“全部”筛选查看。
4. 普通任务同时设置计划日期与不同的截止日，确认分别显示；设置成同一天应只显示一次。
5. 在设置依次选五组主题、调整不透明度，确认主窗口及小组件立即变化；正常退出重开，确认恢复选择。100% 应完全不透明。
6. 检查 80–94% 时桌面合成透明的阅读体验；若不舒服可设 100%。编辑对话框保持清晰、不单独降低透明度。
7. 开启小组件，添加今日任务并完成，确认日历和主窗口同步。仍需人工检查标题栏拖动、置顶和实际位置恢复。

既有未验证边界仍适用：Windows 通知实际展示、真实中文输入法、注销后登录启动、另一台无开发环境机器、休眠恢复及多屏混合缩放。
完全退出后不提醒；程序运行或驻留托盘才检查，重启补检。相关边界见 README。
